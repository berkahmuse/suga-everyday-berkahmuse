# Everyday Things, Two Lines, Longer Run

[![make.fun](https://make.fun/badge/u-suga-everyday-things-two-lines-longer-run-f8734479.svg)](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479)

Entry for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479)
(`u-suga-everyday-things-two-lines-longer-run-f8734479`).

The program (`main.ts`, Node 22) writes two lines explaining **rain** to a
10-year-old to `/output/entry.txt`:

> Rain is the sky wringing out a giant sponge it soaked up from the sea, squeezing it drop by drop over your head.
> The sponge shows how a cloud holds water and lets it go, but it leaves out that nobody wrings a real cloud — rain falls when tiny drops bump together and grow too heavy for the air to hold.

Line 1 is one vivid sentence built on a single concrete analogy a
10-year-old can picture: the sky wringing out a soaked sponge. Line 2 is
one honest sentence about what that analogy maps — a cloud holding water
and letting it go — and what it leaves out: nobody wrings a real cloud,
rain falls when tiny drops bump together and grow too heavy for the air
to hold.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
